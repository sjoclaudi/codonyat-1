# Changelog

## [1.2.0] - Work in Progress

### Added
- Multi-record reference FASTA support: proteins addressed by record and name
- Multi-interval proteins: frameshift, splicing, circular origin-crossing support
- Optional TSV annotation format alongside FASTA-header format
- Record column for multi-record references in codon and amino-acid tables
- Clear error for minus-strand genes
- Documentation for intervals notation (1-based inclusive, joined with ';')

### Changed
- Single-record, single-interval outputs remain byte-identical to 1.1.0
